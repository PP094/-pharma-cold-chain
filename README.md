# 药品冷链监控系统

## 项目简介
本项目为医药物流工程师6个月冲刺计划的核心产出，旨在开发一个满足GSP规范的药品冷链监控系统，包含数据采集、超温报警、实时可视化和短信通知功能。

## 技术栈
- Python (Pandas, Streamlit, requests)
- MySQL (数据库设计)
- 阿里云短信API
